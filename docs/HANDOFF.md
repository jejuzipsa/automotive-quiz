## 6. 작업 완료 정의
- OCR 생성 ≠ 원본 텍스트 확인.
- 원본 정답표 번호 확인 ≠ 기술적으로 정답이 맞음.
- 내부 검수 승인 ≠ 공개 게시 이용허락.
- `source_text_checked=true`, `technical_checked=true`, `rights_cleared=true`를 **서로 독립된 조건**으로 관리하고, 권한 있는 문항만 공개 사이트에 등록.
