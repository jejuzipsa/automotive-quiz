## 4. 사용자 요구사항과 고정 결정
1. 기존 공인중개사와 **동일한 반응형 디자인**, 색상만 자동차정비 초록 계열.
2. 메인 브랜드 아이콘(톱니바퀴)은 유지, **그 외 아이콘은 공인중개사 사이트 파일 6종 사용**.
3. 기존 기출문제 / 책 수록 예상문제를 **투트랙**으로 구분.
4. 해설에서 **독자적인 핵심 개념 퀴즈·괄호문제** 제작.
5. 과목별 4지선다, 해설, 정답/오답 색 구분, 오답 다시 풀기, 실전 모의고사.
6. 원본 상업 교재 자료의 공개 배포는 금지. 비공개 사이트 운영 예정이나 현재 실제 인증/접근제어는 없음.
7. **모든 작업은 GitHub docs 문서에 기록**하고 후속 채팅에서 문서만 읽어도 이어서 할 수 있도록 유지.
