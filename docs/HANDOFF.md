## 2. 화면과 코드
- `index.html`: 홈, 기출/예상 분리, 4과목, 퀴즈, 결과, 오답, 핵심 개념, 샘플 실전시험
- `styles.css`: `gichul-quiz`를 가져온 반응형 디자인, 자동차정비 초록색 팔레트, 다크 모드
- `app.js`: 4지선다 채점, 정답/오답 표시, 해설, 다음 문제, 오답복습, 마지막 학습기록(localStorage), 샘플 시험
- `data/questions.js`: **독립 작성 데모 8문항 + 개념퀴즈 데모 4문항만 공개**
- `tests/validate.cjs`: Node 기본 구조 검사 (`node tests/validate.cjs`)
- `assets/`: 공인중개사 사이트의 섹션/메뉴 아이콘 PNG **6종을 원본 그대로 복사**; 메인 헤더 브랜드 아이콘은 기존 자동차정비 톱니바퀴를 **유지**함.
- `.github/workflows/sync-reference-icons.yml`: 원본 아이콘 6종만 별도 저장소로 복사하는 GitHub Action. **property-icon.png는 복사하지 않음**. 아이콘 파일은 이미 새 저장소에 들어가 있음.

## 3. 실제 사용자 제공 문제은행 — 비공개 보관, 공개 사이트 미등록
- 책: 2026 자동차정비산업기사 필기 기출/예상문제, 스크린샷 원본 57장, 이중 동일 이미지 2장, 고유 55장
- 과목: 엔진정비/섀시정비/전기·전자장치정비/친환경 자동차정비
- 구성: 9회 × 4과목 × 20문항 = **720문항**
- 이 자료는 공식 공개 기출이 아니라 **민간 교재의 기출 복원/예상문제** 트랙.
- QA1~QA5 초기 OCR 텍스트는 오류가 많아 **폐기**. 각 QA 보고서는 역사 기록으로만 남김.
- **QA6만 현재 작업 기준**. 원본 스크린샷 재분할 → 문제 이미지 720개 + 해설 이미지 720개 → 선택지 위치 독립 검출 → 새 OCR 후보 720개.
- QA6 파일: ChatGPT 파일 라이브러리 `/기출문제_자동차정비산업기사/자동차정비산업기사_새OCR_720문항_QA6_검수전_20261122.zip`
- QA6 ZIP SHA-256: `2e1dd405e4f08efc2b26f14109a5ff28bbcdf9aac7e87bdb40a503c4eaf34c37`. 다음 채팅에서 파일을 찾아 **이 해시와 비교**해 오염/버전 혼선을 방지.
- 내부: `bank.json`, `rounds/*.json`, `questions/*.png`, `explanations/*.png`, `ocr-candidates.json`, `manual-overlays.json`, `review.html`, `qa6-summary.json` 등.
- 문자 전수 대조: **10문항 전체 확인**, **3문항은 지문/보기만 확인**, **707문항은 미시작**. 따라서 **710문항의 전체 문자 검증이 남음**.
- 원본 정답표 이미지 36개/정답 번호 720개 추출 및 이전 원본 대조 결과와 교차 확인됨. 그러나 **기술적 정답 검증 0/720**, 승인·공개 **0/720**.
- 모든 실제 출판사 문항 `publishable=false`; 새 공개 Pages 코드/데이터에 **절대 넣지 않는다**.
- QA6의 `quality-report.json` 내부 일부 수치는 수동 전사 오버레이 전 단계의 값이며, 현재 합계는 `qa6-summary.json`과 `bank.json`의 상태 필드가 우선한다.

## 4. 사용자 요구사항과 고정 결정
1. 기존 공인중개사와 **동일한 반응형 디자인**, 색상만 자동차정비 초록 계열.
2. 메인 브랜드 아이콘(톱니바퀴)은 유지, **그 외 아이콘은 공인중개사 사이트 파일 6종 사용**.
3. 기존 기출문제 / 책 수록 예상문제를 **투트랙**으로 구분.
4. 해설에서 **독자적인 핵심 개념 퀴즈·괄호문제** 제작.
5. 과목별 4지선다, 해설, 정답/오답 색 구분, 오답 다시 풀기, 실전 모의고사.
6. 원본 상업 교재 자료의 공개 배포는 금지. 비공개 사이트 운영 예정이나 현재 실제 인증/접근제어는 없음.
7. **모든 작업은 GitHub docs 문서에 기록**하고 후속 채팅에서 문서만 읽어도 이어서 할 수 있도록 유지.

## 6. 작업 완료 정의
- OCR 생성 ≠ 원본 텍스트 확인.
- 원본 정답표 번호 확인 ≠ 기술적으로 정답이 맞음.
- 내부 검수 승인 ≠ 공개 게시 이용허락.
- `source_text_checked=true`, `technical_checked=true`, `rights_cleared=true`를 **서로 독립된 조건**으로 관리하고, 권한 있는 문항만 공개 사이트에 등록.
