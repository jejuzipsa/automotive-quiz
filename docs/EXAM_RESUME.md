# QA69 시험 이어 풀기

- 같은 브라우저에 진행 중인 시험 1개를 저장한다. 문제 ID·내용 서명, 보기 순서, 답안, 현재 위치, 종료 시각 유지.
- 홈 이동·새로고침 이후 이어 풀기 가능. 시험 시간은 계속 흐르며 만료 시 저장 답안으로 채점. 새 시험으로 덮어쓰기 및 삭제 전 확인.
- 공개 문제은행에서 철회되거나 내용이 변경된 문항이 있으면 이전 시험 복원 차단. 일반 연습 및 개별 복습은 범위 제외.
- 동일 브라우저 전용, 기기 간 동기화 미지원. 브라우저 저장소 차단/삭제 시 복원 불가. 클라이언트 시계 기반 학습용 타이머.
- Node 모의 DOM 검사에 홈 복귀, 선택지 순서, 답안/마감시각 유지, 만료 채점 추가. 실제 모바일·새로고침 검사는 QA68과 통합한 뒤 별도 확인 필요.
- 공개 112문항 및 720문항 승인 게이트 불변.
