# QA38 — 720문항 전수 무결성/과목 보류 재심사 대기열

작성: 2026-11-23. **정답/근거의 독립 기술 최종 승인 아님**. 자기작성 재구성 초안을 검수한 자료야.

## 전수 검증 사실
- 9회×4과목×20문항 = **720문항/2880선지** 질문-해설 ID·정답/오답 판정·4선지·검수 기록 연결 재검사.
- **1차 자료 근거 부합 351문항, 추가 검토 369문항(차종·과목·안전 366 + 품질 검토 3)**. 351문항도 독립 기술승인이 아니라 과거 1차 근거대조 기록이야.
- **과목 보류 55문항**, 실제 재분류 확정 0. 전수 텍스트 정규화 3-gram/Jaccard 0.53 기준 **유사·정확 문구 후보 0쌍**. 이는 *동일 학습목표·의미 중복이 없다는 뜻이 아님*. QA29~QA37에서 발견한 중복 교정은 이 문자열 알고리즘만으로 검출할 수 없어.
- 처음 발견된 59개 URL 파서 경고는 **기존 `reference_urls` 별칭 사용 39개(형식차, 링크 누락 아님)**와 **QA26 7회 엔진 20개의 `source_urls` 단일 문자열(비표준 실제 구조)**로 분리했어. 20문항의 질문·해설·감사 JSON을 URL 배열 형태로 통일하고 테스트를 강화했으며 현재 구조오류 **0건**.
- 선지 자체와 정답번호는 위 형식 수정 때문에 바꾸지 않았어.

## 공식 기준 및 유효성 한계
- [Q-net 자동차정비산업기사 공식 출제기준 게시물](https://www.q-net.or.kr/cst006.do?artlSeq=5213442&brdId=Q006&code=1202&gId=&gSite=Q&id=cst00602) 적용기간 **2025-01-01~2027-12-31** 확인. 다만 게시물의 **첨부 HWP 세부 분류표는 아직 열람하지 못했기 때문에** 개별 분류 판정의 최종 근거로 사용하지 않아.
- QA38 URL 점검은 **HTTPS·배열 형태만 검사**. 해당 링크가 현재 열리는지, 원문이 개별 선택지 주장에 맞는지는 별도 검증이 필요해.
- [QA38 CI 검증 소스](../tests/qa38-final-review-queue.test.cjs), Actions 아티팩트 `qa38-final-review-queue`에는 과목 보류 55건, 정답위치 분포, 어휘 중복 후보·내용난도 검토 대상 목록을 보존해.

## 분류 오탐과 보류 유지
- **6회 친환경 20번** `auto-made-r06-s04-q20`: 초기 심사에서 *가정용 태양광 인버터*의 과목 이탈로 보류했지만, 현행 문항은 *전기차 구동배터리 직류를 3상 교류 모터에 공급하는 인버터*로 재작성됐어. 예전 사유가 현행 질문에 맞지 않는다는 **이력 불일치**를 확인했어.
- 과거 보류 사유는 변경/삭제하지 않고 `qa38_original_reason`, `qa38_current_question_review_note`, `qa38_recheck_status`를 질문·해설에 나란히 붙였어. **보류 상태 `hold_do_not_publish`는 유지**, 공식 세부기준과 독립 감수 후 재평가해.
- 엔진에 배치된 타이어, 섀시에 배치된 터보·연료레일, 친환경에 배치된 일반 제동·ATF·SRS 등 나머지 보류도 무조건 이동시키지 않고 상세 출제기준 및 80문항/4과목 정원 구조를 기준으로 다시 검토해야 해.

## 출제·철수 보호
- **독립 기술 최종승인 0/720**, 재구성 기출 공개 **0/720**, 공개 자체제작 예상문제 **80** 유지.
- 개인정보/구매교재 OCR 원문을 공개 저장소에 올리지 않았고, `data/manifest.json`/공개 문제 UI/모의고사 변경 없음.
- 최종 전문감수와 게시권리 확인·비공개 백업의 해시 및 복원 테스트 전 공개 초안 파일을 임의 삭제하지 않아.
