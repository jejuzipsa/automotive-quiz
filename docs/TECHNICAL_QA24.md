# QA24 — 6회차 섀시정비 20문항·80선지 기술자료 1차 검토

작성: 2026-11-23 / QA23 직후 최신 자체 재작성 편집 초안

## 검수 결과

6회 섀시정비 질문20·개별 해설20·보기80개를 각각 확인하고 정답/오답의 기초 물리·자동차 정비원리와 제조사 기술자료 참고를 기록했어. [QA24 섀시 80선지 JSON](../data/qa/technical-qa24-r06-chassis-option-audit.json)에 문제와 네 보기의 판단 이유/자료 URL/보류 사유가 있어.

| 항목 | 건수 |
| --- | ---: |
| 4선지별 판단 이유 검토 | **20문항·80선지** |
| 기술자료와 일반원리 1차 부합 | **6문항** (5·7·9·11·14·15) |
| OEM·안전·과목 분류 추가 검토 | **14문항** |
| 신규 문안 직접 수정 / 신규 분류 보류 | 0 / 0 |
| 독립 전문 기술 최종승인 / 기출 복원 웹 신규공개 | **0 / 0** |

**자료 참고와 최종 승인 사이에는 큰 차이가 있어.** 현재 출제은행에 추가할 근거가 아니고 각 문항의 `publishable:false`, `pending_independent_review`는 그대로 유지해.

## 주요 검토·보류

- **1·2번 ATF/변속 유압**: 변속기의 색상·냄새만으로 클러치 불량을 확정할 수 없고, 특정 축압기 설계는 해당 변속기 유압회로를 확인해야 해.
- **3·4번 변속기 분해/탈거**: 고온 ATF 화상, 리프트 고정·주변 배관·샤프트·하네스 탈거는 차량별 작업 안전절차 필수.
- **6·8번 유압식 차고 제어**: 고압 작동유 누설·규정압력·보정은 차종별 안전·측정 절차 필요.
- **10번 전자제어 댐퍼**: 솔레노이드/배선의 실제 저항 규격·측정온도·연결 방식은 부품별 OEM 기준 확인.
- **12·13번 EPS 소음/영점**: 모터·감속기 기계음 분리, 조향각 학습 시 서비스 절차는 제조사/계측 조건 확인.
- **14번 제동력시험기 vs ABS**: 롤러 시험은 차륜의 기계적 제동력 측정, ABS 센서 신호/전자제어 로직은 별도 진단이 필요하다는 차이를 확인.
- **15번 액티브 ABS 휠속도 센서**: [HELLA 능동/수동 ABS 센서 비교](https://www.hella.com/techworld/en/technical/sensors-and-actuators/check-and-change-abs-and-wheel-speed-sensors/) 근거를 대조해, 액티브 센서는 설계에 따라 전원·전류형 신호를 사용하고 수동 유도센서만의 AC 사인파와 구별함.
- **16~20번 기존 과목 분류 보류**: 터보 오일 드레인·실링 와셔·과급 누설·엔진 ECU·지르코니아 협대역 산소센서는 섀시가 아니라 엔진정비 직접 범위일 가능성이 높아 **기존 `hold_do_not_publish` 5건 모두 유지**. [Garrett 터보 오일 드레인](https://www.garrettmotion.com/knowledge-center-category/racing-and-performance/turbocharger-oil-leakage-troubleshooting/), [Bosch 람다센서](https://www.bosch-mobility.com/en/solutions/exhaust-gas-treatment/switching-type-lambda-sensor/)의 기본원리와 대조했지만 차량별 안전/진단규격은 보류.

## 누적 상태

QA23까지 6회 엔진20 포함 **420문항·1680선지**, QA24 섀시20·80을 더해 **440문항·1760선지**에 역사적 선택지별 1차 이유 기록. 아직 문항 선택지별 개별 기술근거 검수가 없는 **280문항**(6회 전기20·친환경20 + 7~9회 240)이 남아 있어.

**현재 과목 분류 보류55, 독립 기술 최종승인0/720, 기출 복원 사이트 공개0/720.** 기존 학습용 예상문제80 모의고사 및 공개 매니페스트/비공개 QA23 OCR 원본 변경 없음.

다음: 6회 **전기·전자20 → 친환경20**, 이후 7~9회 각80. 기술적 독립 최종승인·게시권리 확인 전에는 초안 문제를 공개시험에 포함하지 않아.
