## 2026-11-22 — QA1~QA5, 원본 품질검수 이력 (과거, 폐기한 OCR)
- 구입한 예상/기출복원 교재 캡처 57장 중 완전 중복 2장(고유 55장).
- 처음 OCR로 720문항 생성했으나 전문용어, ①~④, 2단 보기 배열 등 인식 오류 다수 발생.
- 정답표 번호 80건 OCR 오인식 교정, 원본 정답표 720개 숫자 대조.
- 원문 100문항까지 교정한 QA5와, 기술적 의심 문항 26건의 이력 존재.
- **사용자 요청에 따라 QA1~QA5의 OCR 문장 전부 새 문제은행에는 사용하지 않음.** 이 단계의 수정건수와 OCR 오류 수는 새 QA6 검증된 문항 수에 합산하지 않음.
- 검수 기록은 `gichul-quiz`의 Draft PR #114 (개인에게 공개되지 않는 출판사 원문 제외)에 남아 있음.

## 2026-11-22 — QA6 원본 이미지 기반 재구축 (현재 기준)
- 원본 55장 → 문제/선택지 원본 이미지 720장 + 해설 이미지 720장.
- 독립적으로 4개 선택지 위치 검출 후 질문·해설 재OCR: 후보 720문항 모두 생성.
- 해설 209문항 재인식, 그중 160문항의 인식 지표 개선(원본 전사 승인 아님).
- 문자 원문 전체 대조 10문항, 지문/선택지 부분 대조 3문항. 707문항은 미착수.
- 정답 번호 720개 원본 표와 대조함. 정답 기술검증/배포 승인 0.
- QA6 ZIP 개인 파일 라이브러리 보관; 경로와 SHA-256은 `docs/HANDOFF.md` 참조.
- 현재 웹사이트는 출판사 원문 없이 **샘플 사이트**로만 운영.
