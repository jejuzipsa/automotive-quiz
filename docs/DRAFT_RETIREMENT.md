# 공개 초안 파일 철수 계획 (최종 검수 이후)

## 사용자 결정 (2026-11-23)
지금은 자체 재작성 기출 편집초안 720개를 GitHub에서 검수하며, 전체 1차 검사·후속 교정 종료 뒤 공개 저장소의 **미사용 초안 파일을 치우는 방식**을 선호함. 현재 진행 중에는 원본 검수 이력과 테스트를 보존해야 하므로 **아직 삭제하지 않음**.

## 단계별 처리
1. 7~9회차까지 총 720문항 1차 검수 완료하고 OCR 원본(개인 QA23)과 재작성 초안의 출처·정답·과목·중복·기술/권리 승인 구분 완료.
2. 삭제 전에 모든 `data/past/drafts`, `data/explanations/drafts`, `data/qa`의 원본을 **접근 제한된 개인 저장소 또는 로컬 보관소**로 이관하고 SHA-256/파일개수와 복원 여부 검사.
3. 사이트에서 쓰는 `data/manifest.json`과 공개 예상문제 80문항을 보존한 상태에서 사용하지 않는 초안 JSON/감사 파일·관련 테스트를 **의존성 확인 후** 공개 main 브랜치에서 제거.
4. 주의: GitHub의 기존 커밋 SHA, PR, Actions 아티팩트, 외부 복제본에는 삭제 전 내용이 여전히 남을 수 있음. 필요 시 GitHub 공식 절차에 따른 히스토리 재작성·비밀정보/저작권 노출 대응, 포크/캐시 정리 검토.
5. 역사 재작성은 공동작업자 브랜치 및 PR/배포에 영향을 주므로 별도 이관·검증 후 진행. 단순 삭제가 과거 공개를 취소하지 않는다는 점을 인계 문서에 명시.

## 현재 절대 지킬 원칙
- 사용자 구매교재의 원본 OCR·이미지는 공개 저장소에 올리지 않음.
- `publishable=false`, `technical_answer_status=pending_independent_review`인 초안은 `manifest.json`에 연결하지 않음.
- 최종 기술 승인과 게시 권리가 확보되기 전까지 공식 기출문제로 표시하거나 공개 출제로 승격하지 않음.

## 2026-11-23 — QA37 전수 1차 근거기록 완료 이후 확인

- 720문항/2880선지에 대한 1차 정오 이유/참조링크 기록은 완료했어. **이는 기술·법령·안전·저작권의 독립 최종승인이 아님**(현재 0/720).
- 후속 전문감수와 게시권리 확인, 중복/난도·과목 후보 최종 처리 전에 공개 저장소 초안을 자동으로 삭제하지 않는다. 삭제 전 비공개 백업의 파일개수/해시·복원성 확인이 필요해.
- GitHub `main`에서 삭제하더라도 과거 커밋, PR, 포크, CDN/외부 복제본에 원문이 남을 수 있으므로 실제 비공개 필요 수준에 맞는 대응 계획이 선행되어야 해.
