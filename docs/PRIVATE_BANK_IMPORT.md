# QA7 로컬 개인 문제은행 — 사용법·기술 구조·비공개 경계

## 사용법

1. 사이트 `https://jejuzipsa.github.io/automotive-quiz/`의 **내 문제은행** 클릭 또는 직접 `/private.html` 접속.
2. ZIP 선택 화면에서 파일 라이브러리의 **자동차정비산업기사_QA7_원본20문항대조_개인용_20261122.zip**을 **압축 해제하지 않은 채** 선택.
3. 화면에 **총 720문항** 표시를 확인하고 과목(4개), 회차(1~9), 문제 수(10/20/전체), 순서(번호순/무작위) 설정.
4. 출제된 **원본 문제 이미지**를 읽고 번호 ①~④ 선택 → **교재 정답표 기준** 파란색 정답/빨간색 오답 표시 → **원본 해설 이미지** 확인.
5. 다음 문제, 결과, 오답 다시 풀기를 이용. 각 문항에 원본 문자 대조 상태를 표시함.

## 기술 구조
- `private.html` + `private-bank.js` + `private-bank.css` + `vendor/jszip.min.js` (JSZip 3.10.1, MIT/GPL dual license).
- 사용자가 로컬에서 선택한 파일을 `JSZip.loadAsync(File)`로 브라우저 내부 메모리에서 열고, `bank.json`/PNG 경로를 검사한 뒤 필요한 이미지만 차례대로 디코딩.
- 720개의 고유 문항 ID, 9회×4과목×20문항, 각 이미지 파일 존재 여부, 정답 1~4를 검사.
- 일반 퀴즈의 텍스트 엔진과 **분리**함. OCR 후보로 출제하지 않고 원본 문제/해설 이미지를 보여줌.
- 출판사 원문, 선택지, 해설, 이미지는 GitHub 저장소에도, Pages에도 없음.
- 선택된 ZIP 파일의 내용에 대해 **네트워크로 송신하는 코드가 없음**. 페이지 JSZip 라이브러리는 GitHub repo 내 정적 파일로 로드되며 CDN 없음.
- ZIP은 메모리에서만 보관. **새로고침/브라우저 재실행 시 다시 선택 필요**. 오답도 현재 열린 탭 메모리에서만 보관. PC/아이폰 사이 자동 동기화 없음.
- 공개 `private.html`의 버튼 자체는 누구나 볼 수 있으나, 사용자 ZIP 없이는 교재 질문이 나타나지 않음. **비밀번호/로그인 보호형 비공개 사이트가 된 것은 아님.**
- QA7 ZIP ~49MB. 모바일 특히 iPhone Safari에서는 파일 로딩 시간이 걸릴 수 있고 아직 실제 기기 테스트는 완료하지 않음.

## QA7 파일
- ChatGPT 파일 라이브러리: `/기출문제_자동차정비산업기사/자동차정비산업기사_QA7_원본20문항대조_개인용_20261122.zip`
- SHA-256: `136b5c74ec147d9a3ea410911025572d19344ed64371fd0cc150ee50fc6f50fe`
- ZIP 검사: 720개의 문제 PNG + 720개의 해설 PNG, JSON ID·정답·이미지 링크 검증 통과, ZIP 손상 없음
- 원본 텍스트 대조: 1회 엔진정비 1~20번 **20문항 전체**. 3문항은 지문/보기만 별도 대조. 나머지 **697문항 원문 대조 미착수**.
- 기술적 정답 최종 승인: **0/720**. 이 개인용 문제풀이 화면은 **교재 정답표 일치 여부만 표시**함.

## 저작권/안전
- 구매 교재 스크린샷, OCR 문장과 해설을 공개 Pages 저장소에 밀어넣거나 프론트엔드 코드에 JSON으로 하드코딩하지 말 것.
- 공개 저장소를 Private으로 바꿔도 GitHub Pages 자체가 자동 비공개가 되지 않음.
- 나중에 서버 기반 동기화/로그인 필요하면 서버 측 인증, 파일 접근 정책, 사용 권한을 별도로 설계.

## 테스트
- 정적 검사: `private-bank.js` JS 문법 및 HTML 요소 41참조 모두 실제 존재.
