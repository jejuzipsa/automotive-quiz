# 개인 보관 기출 실전 시험

실전 시험 화면에서 개인 보관용 JSON을 선택하는 별도 시험 페이지를 추가했다. 자료 원문은 GitHub에 저장하지 않으며 브라우저에서만 읽고 IndexedDB에 저장한다. 8회차 원문 80문항·120분, 보류 제외 참고 점수와 원문 표시 정답 기준 참고 점수, 수정 학습문항 별도, 그림/MathML 표시, 진행 기록 및 삭제. 공식 합격 판정 없음. 기존 출제 및 저장 기능 변경 없음. 공개 재배포 권한 미확인. 실제 개인 자료 파일은 사용자가 별도로 보관한다. 신규 페이지는 독립 구현이며 기존 시험 기록과 합산하지 않는다. 실제 iPhone Safari 확인 및 운영 사이트 검증 필요.

최근 시험 결과를 브라우저에 저장하며 다시 열 수 있다. 합성 자료를 이용한 Chromium 회귀검사 추가(실제 개인 자료는 공개하지 않음). 시험 중 타이머는 절대 종료시각으로 유지한다.
