# 회차별 기출 실전 시험

사용자 요청으로 검수 05 제공 JSON을 회차별 8파일 및 공용 그림/수정 문항 JSON으로 분리, 실제 기출 640문항(458/110/72)과 그림 98개·수정 학습문항 9개를 자동 로딩. 파일 업로드 UI 및 외부 시험 링크 제거, 기존 개인 시험 진행/결과 저장 키와 review05 버전 유지. 원래 시험 번호/보기/정답/해설/검수 상태 보존. 공식 확정 정답 검증 또는 전문가 감수 완료로 표시하지 않음. 기존 1,440/112/800/8 은행 변경 없음. 실제 데이터 Chromium 회귀검사 추가.

실전처럼 시험 보기에서 날짜를 선택하면 해당 회차를 바로 시작한다. 공용 그림·수정 문항 JSON은 먼저 로딩하고, 회차 JSON은 선택·이어 풀기·최근 결과 조회 시 해당 1개만 로딩한다. 같은 페이지 내 이미 로딩한 회차는 재사용하며 로딩 오류 시 기존 저장 기록을 유지하고 재시도할 수 있다. 회차 선택 화면에서 이어 풀기·최근 결과·수정 학습문항을 사용할 수 있다. 시험 진행 기록은 브라우저별이며 기기 간 동기화 없음. 자료 출처는 회차 JSON의 source에 보존한다. 원문과 AI 해설, 교정 해설 및 보류 상태를 구분한다.
