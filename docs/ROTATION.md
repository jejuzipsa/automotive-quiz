# 1,440문항 개인 로테이션 사용법

운영 사이트: https://jejuzipsa.github.io/automotive-quiz/

1. 제공받은 `automotive-light-720.json`을 기기에 저장한다.
2. 홈의 **개인 JSON 선택**에서 해당 파일을 선택한다.
3. 1,440문항 연결 완료, 과목별 360문항을 확인한다.
4. 개인 로테이션 탭에서 10·20문제 또는 전체 보기 → 문제 풀기. 실전 모의고사에서는 개인 로테이션 80문제 시작을 선택한다.

기존 재작성본 720개(82개 후속 수정 적용)와 원본 기반 표현 수정 720개를 결합한다. 선택한 개인 파일은 서버로 전송하지 않고 현재 브라우저에 저장된다. 기존 재작성 자료는 공개 GitHub에서 읽는다. PC와 아이폰은 각각 최초 한 번 파일 선택이 필요하다. 브라우저 데이터 삭제/개인 은행 제거 시 다시 연결해야 한다. 기기 간 학습기록 동기화는 아직 없다.

로테이션은 과목별 출제 대기열을 저장하며 새 세션에 배정한 문항을 소비한다. 중간 종료한 세션의 미응답 문제도 배정된 것으로 처리된다. 기존 오답 기록 기능은 유지한다. 원본 기반 정답·해설은 교재 기준이며 실제 정비 작업 절차나 최신 법령을 보증하지 않는다.
