# 자동 로테이션 사용법

https://jejuzipsa.github.io/automotive-quiz/

접속하면 기본 기출 기반 로테이션에 과목별 360문항, 총 1,440문항이 자동 연결된다. 파일 선택은 없다. 10·20문제 또는 전체 보기를 이용한다. 실전 모의고사에서 기출 기반 로테이션 80문제를 선택한다. 기존 예상 112문항, 개념 800문항(과목별 200문항), 샘플 8문항은 별도 유지한다. 홈의 핵심 개념 퀴즈 카드에서 10문제·20문제 또는 ‘괄호문제 · 200’(전체 풀기)을 바로 선택한다.

로테이션은 과목별 출제 대기열을 브라우저에 저장한다. 시작 시 배정된 문제는 풀이 여부와 무관하게 대기열에서 차감된다. 같은 기기에서 새로고침 후에도 유지되며 기기 간 동기화는 없다. 기존 질문 ID 및 내용 서명은 유지한다.

공식 기출 인증 또는 독립 전문가 승인으로 표시하지 않는다. 학습용이며 공개 페이지 및 저장소에서 접근 가능하다. 원본 파일 대신 사용자 제공 최소 수정 JSON의 학습 필드만 저장한다.
