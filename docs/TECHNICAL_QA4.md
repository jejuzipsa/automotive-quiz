# QA4 — 1회차 섀시정비 20문항 편집·중복·과목경계 검수

일자: 2026-11-23. 기준: `data/past/drafts/chassis.json`과 동일 ID의 별도 해설 20개.

## 이번에 실제 확인한 범위

1회차 섀시정비 1~20번 **질문·4개 선택지·기록된 정답·해설**을 읽고 문항의 편집상 중복·주제 분류·선지 품질·해설 연계 문제를 점검했다. 상세 전수 메모는 [편집 감사 JSON](../data/qa/technical-qa4-chassis-r01-editorial-audit.json)에 정리했다.

**중요: 20문항의 80개 선택지를 각각 제조사·기술자료로 독립 검증한 것은 아니다.** 이번 배치의 보기별 기술검증 완료 0, 내용 직접 교정 0, 독립 최종 기술승인 0, 사이트 신규 기출 출제 0이다. QA3 엔진 20문항의 1차 선지검수 17/3은 별도 이력이다.

## 발견한 후속 검토 후보

- **문항 13·19 — 근접 중복**: 13번의 'EPS 조향 토크 센서의 역할'과 19번 'EPS 제어기가 운전자 조향 힘을 판단할 때 쓰는 입력'은 둘 다 조향 토크 센서가 운전자의 조향 입력을 감지·전달하는 내용이 정답이다. [Bosch EPS 기술자료](https://www.bosch-mobility.com/en/solutions/steering/electric-power-steering-systems/)에도 같은 기본 기능이 설명돼 있다. 동일 모의고사에서 변별력을 위해 둘 중 한 문제를 다른 진단 개념으로 바꾸는 편이 좋다. **완전 동일 문자열 중복은 아니므로 자동 삭제나 정답 변경을 하지 않았다.**
- **문항 10 — 해설 연계**: 가변 댐퍼 제어 목적은 감쇠력 조절인데, 기존 해설의 마지막 문장은 선지에 없는 '엔진 연료분사장치'와 비교한다. 정답 번호의 오류로 단정하지 않고, 다음 문안 교정 대상으로 표시했다.
- **문항 2·4 — 과목 검토 기존 보류**: 2번의 연료레일 압력/펌프(엔진정비 관련), 4번 ECU 통신·전원/접지(전기·전자 계통 경계)는 기존 `hold_do_not_publish`를 유지한다. 임의로 과목을 옮기지 않았다.
- **문항 11·16, 14·18 — 학습목표 반복 후보**: 전원·퓨즈 점검, EPS 보정 주제가 각각 유사하다. 완전 중복으로 확정하지 않고 독립성을 재검토한다.
- **문항 6·8·12 — 안전·제조사 절차 주의**: 잔압 감압, 제동유압 점검, ECU 안전 분리 절차는 차종별 정비지침을 확인한 뒤 최종 승인한다.
- **문항 17 — ABS 경고등 해설 1차 자료 확인**: [HELLA ABS/ESP 기술 설명](https://www.hella.com/techworld/en/technical/car-electronics-and-electrics/abs-esp-control-units-for-braking-and-driving-dynamics/)은 ABS 고장표시등과 기능 이상의 연관성을 뒷받침한다. **이 1개 개념 확인은 4선지의 기술적 최종 검증과 다르다.**

## 다음 작업과 공개 원칙

1. 13·19 중복 유형을 수정할 경우 새 질문·4선지·별도 해설의 정합성을 함께 교정하고 기존 QA1 편집 이력을 보존한다. 10번 해설 문장도 선지와 직접 연동하도록 수정.
2. 2·4번 과목 경계를 Q-Net 세부 시험 출제 기준과 기술자료를 통해 판단. 47개 기존 분류 보류 전체 수량을 임의로 감소시키지 않는다.
3. 섀시 20문항의 각 4선지를 제조사 정비기술자료로 검증해 근거·조건·정답 유일성을 기재. 안전·수치·차종별 절차는 고위험 우선.
4. 엔진 QA3 보류 13·16·20도 병행. **독립 최종 기술승인 및 게시권한 검증 완료 전에는 해당 기출 복원 초안을 공개용 출제 매니페스트에 넣지 않는다.**
