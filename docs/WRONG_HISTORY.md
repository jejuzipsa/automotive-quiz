# QA70 누적 오답 노트

- 브라우저 localStorage에 문제 ID, 내용 서명, 정답/오답/미응답 횟수, 최근 결과, 최종 시각을 기록한다. 내용 서명은 지문·보기·정답·해설을 직렬화한 문자열이다(해시가 아님). 과거 서명으로 문제를 복원하지 않으며 현재 공개 데이터와 서명이 일치할 때만 표시한다.
- 연습/개별 복습은 답안 선택 즉시 1회, 시험은 제출/만료 시 각 문항 1회 집계한다. 시험 도중 변경한 답은 최종 답만 집계한다. 미응답은 오답률 분자에 포함하지만 별도 횟수로 표시한다.
- 다시 맞히면 복습 완료로 이동하고 또 틀리면 복습 필요로 돌아온다. 과목 필터, 상태 필터, 누적 풀이 횟수·오답률을 제공한다.
- 이전 버전은 마지막 시험/연습만 저장했으므로 해당 기록만 1회 가져온다. 이전 누적 이력 복구 불가. 지문/선택지/정답/해설 변경 시 해당 문제의 과거 기록은 현재 집계 제외.
- 같은 브라우저 전용. 기기 간 동기화 및 동시 여러 탭의 원자적 갱신 미지원. 저장소 삭제 시 이력 소실. 공식 성적이 아닌 학습용 통계.
- Node 및 실제 Chromium 회귀 검사를 추가한다. 공개 112문항 및 720문항 승인 게이트 변경 없음.

- QA71: 손상된 횟수/상태 레코드 제외, 중복 ID는 최신 유효 기록 하나만 사용. 오답 목록 복습의 복귀 버튼 문구는 실제 목적지와 일치.
