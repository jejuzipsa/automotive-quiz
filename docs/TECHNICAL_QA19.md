모든 5회차 질문·해설 원문을 확인해 중복과 과목 경계를 직접 검토했지만, **5회 섀시·전기·친환경 60문항과 6~9회 320문항의 각각 4보기 기술자료 대조는 아직 완료하지 않았다**. 이 380문항은 별도의 자동 위험도 목록으로 관리해.

## 내용상 실제 교정 3문항

[QA19 수정 전후 JSON](../data/qa/technical-qa19-r05-edits-and-holds.json)에서 문제·보기·해설의 수정 전후와 정답 위치를 대조할 수 있어.

- **5회 전기11**: 10번과 반복된 히터코어 냉각수 누설 증상을 다시 묻는 문항 → **온도 혼합도어(블렌드 도어) 명령·위치 피드백과 기계적 걸림 진단**으로 수정, 정답 위치4 유지. 제조사 서비스 [NHTSA 등록 정비자료](https://static.nhtsa.gov/odi/tsbs/2021/MC-10194024-9999.pdf)·[HELLA 공조](https://www.hella.com/techworld/en/technical/car-air-conditioning/car-air-conditioning/)를 편집 참고.
- **5회 친환경17**: 16번과 동일한 수소 누출 검지장비의 역할 반복 → **수소 누출경고에서 실제 누설·센서 신호·DTC 원인 구분**으로 수정, 정답 위치4 유지. [DOE Hydrogen 안전/누출 감지](https://www.energy.gov/cmei/fuels/doe-safety-codes-and-standards-activities) 참고. 구체적 고압가스 작업절차는 별도 OEM 전문승인 전까지 보류.
- **5회 친환경18**: 10번 DC-DC 변환기 역할을 다시 묻는 문제 → **12V 보조배터리 충전 이상 시 LDC 출력전압·전류·DTC/전원상태 진단**으로 수정, 정답 위치4 유지. [BorgWarner 전력전자](https://www.borgwarner.com/technologies/power-electronics)·[자동차 OEM 12V 회로 정비 TSB](https://static.nhtsa.gov/odi/tsbs/2020/MC-10175779-9999.pdf) 참고.

세 문항은 내용 개선 후에도 **`editorial_draft`, `pending_independent_review`, `publishable:false`**. 문항을 편집하는 데 참고한 자료가 모든 보기의 정답 유일성을 증명한 것은 아니며, **5회 전기11/친환경17·18의 신규 선택지는 후속 4선지별 기술검수 대상**이야.

**5회 엔진9**는 렌터카·자동차 분류/관리 문제로 엔진정비 과목과 동떨어져 섀시 또는 자동차관리 관련 영역일 가능성이 높아 **신규 `hold_do_not_publish`**. 기존 52+1 = 현행 **53개**. 과목 공식 변경은 하지 않았어.

## 5회 엔진정비 보류 이유

- **1번 터보 저과급**: 액추에이터·센서·흡기누설의 차종별 제어 정보 필요.
- **2번 크랭크축 저널**: 베어링 표준/언더사이즈 규격 및 OEM 허용 연삭치수 직접 확인.
- **7번 디젤 분사구동파형**: 솔레노이드/피에조 방식, 계측기 고압 안전·펄스규격 확인.
- **9번 차량·렌터카 분류**: 새 과목 범위 보류.
- **10번 인젝터 보정값**: 음수/양수 기호와 데이터 단위의 차종별 해석.
- **11번 ECU 교체**: 보안·인젝터 학습 및 OEM 접근 권한.
- **15번 링 엔드갭·16번 크랭크 풀리 볼트·17번 냉간 밸브간극**: 제조사별 수치·체결조건 필요.
- **19번 배출가스 허용기준**: 2026 국내 법령/적용연도·검사방법 검증 필요.

## 5~9회 400문항 전체 자동 위험 검토 목록

`tests/qa19-round05-09-risk-queue.test.cjs`는 5~9회차 400문항과 400개 별도 해설을 모두 읽고 **선택지 4개 고유성, ID/회차/과목, 정답-해설 정합성, 미승인 공개상태**를 검사한다.

또한 **중복 지문 후보, 같은 과목·회차의 유사 지문 후보(문자 3-gram Jaccard 0.55 이상), 80자 미만 짧은 해설, 수치·단위·절대표현, 고전압·수소·브레이크·고압연료 안전, 법령/기준의 시행시점, 과목 분류 보류, 주제와 이질적인 보기 후보**를 ID별로 우선순위화한다. 결과는 GitHub Actions 아티팩트 **`qa19-r05-r09-review-queue`**의 `qa19-review-queue.json`에 저장돼.

**중요**: 자동 분류는 오탐/미탐 가능성이 있으며 *기술적으로 잘못된 정답·보기 확정이 아니다*. 개별 원문·선지를 자료와 대조해 확인할 사람의 검수 대기열이지, 전체 400문항 기술검수 완료 증거가 아니야.

## 누적 진행

- **1~4회차**: 320문항·1280선지 최신판 개별 1차 근거 기록.
- **5회 엔진정비**: 20문항·80선지 신규 개별 1차 근거 기록.
- 합계 **340/720문항, 1360/2880선지**에 선택지별 1차 판정 이유 존재.
- **5회 섀시·전기·친환경 + 6~9회차 = 380문항·1520선지**의 개별 기술 근거검수는 아직 남아 있음. 나머지는 자동 위험도 목록으로 분류.
- **과목분류 보류53**, 독립 전문 최종 기술승인 **0/720**, 기출 복원 신규 공개 **0/720**.
- 80문항 학습용 자체제작 예상문제 모의고사는 이미 사이트에서 제공 중이며, **공개 `data/manifest.json`과 구매 자료 OCR 원본은 변경하지 않았어**.
