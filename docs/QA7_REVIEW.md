# QA7 정밀 검수 — 원본 11~20번 / 사이트 개인 은행

## 범위
- 사용자가 제공한 QA6 ZIP의 원본 문제 이미지/해설 이미지 카드 `auto-r01-s01-q11`~`q20`을 새로 열어 육안으로 원문 대조.
- 수정 10문항의 지문/보기 4개/해설은 **개인용 QA7 ZIP의 `bank.json`과 `manual-overlays.json`에만 저장**. 공개 저장소에는 저작물 전문 미포함.
- 기존 최초 10문항까지 합쳐 **전체 원문 전사 대조 20/720**.
- 부분 문자 전사 3문항, 나머지 697문항 원문 확인 시작 전.
- 정답표 번호는 QA6에서 원본 표와 대조한 값을 유지, **재점검했지만 기술 정답 승인하지 않음**.

## 기술적 오류·모호성 — 원본 문장을 바꾸지 않음
- **r01-s01-q11** 압축 압력 저하의 '첫 번째 원인'을 실린더 헤드 가스켓만으로 단정. 피스톤 링·밸브·밸브 타이밍도 낮은 압축의 원인이 될 수 있음. 추가 진단 근거 필요.
- **r01-s01-q16** 모든 실린더의 압축압력이 낮은 사례를 헤드 가스킷 고장으로 단정. ASE 학습자료와 미 해군 정비 지침에서는 밸브 타이밍/링 마모도 주요 후보로 제시. **원문 정답이 의심됨**, 검증 전 게시/정답 승인 금지.
- **r01-s01-q17·q19** 삼원촉매의 기능을 거의 동일한 취지로 반복. 2문항을 중복 후보로 기록(삭제하지 않음). 설명의 '완전 무해'는 과장 가능.
- **r01-s01-q18** NOx가 광화학 스모그 원인인 건 타당하지만 '대기오염의 주요 원인'이라는 선택 범위가 광범위해 맥락 검토 필요.
- **r01-s01-q20** 산소 센서는 일반적으로 배기 계통의 산소 함량을 측정함. 원문 해설의 '연소실에서 혼합비 측정'이라는 설명은 **기술 사실 오류**. Bosch 산소 센서 설명 확인.
- **r01-s01-q12** CRDI 테스터의 분사 타이밍·분사 패턴 등 상세 측정 가능 범위를 장비 모델과 시험조건 없이 일반화.
- **r01-s01-q13** ECU 분해 전 배터리 차단의 '무조건 첫 번째' 절차는 제조사/차종별 작업 조건 확인 필요.
- **r01-s01-q14** 냉각수를 확인하는 문제이지만, 뜨거운 냉각계 캡 개방 방지 등 안전 주의 누락.
- **r01-s01-q15** 연료필터 공기빼기 절차는 차종/시스템에 따라 다를 수 있음.
